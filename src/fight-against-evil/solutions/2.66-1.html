2.66 · Esfera com densidade de carga variável

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição do enunciado

Uma esfera maciça não condutora possui uma distribuição de carga volumétrica dada por ρ(r) = (β/r) sen(πr/2R). Determine a carga total contida na região r < R e r > R. Mostre que as duas expressões para o campo elétrico se igualam em r = R.

1. Distribuição e carga encerrada

R é o raio da esfera e β é uma constante. A densidade dada vale no material, para 0 < r < R; fora da esfera, ρ = 0. Calcularemos a carga encerrada Qenc(r) por uma superfície esférica de raio r, a carga total Q da esfera e o campo elétrico nas duas regiões.

Para r > R, a superfície gaussiana contém toda a carga da esfera. Isso é diferente da carga situada exclusivamente na região exterior r > R, que é zero.

Como ρ depende apenas da distância ao centro, usamos cascas esféricas de raio s e espessura ds. Seu volume é dV = 4πs² ds. Definindo α = π/(2R), temos:

dQ = ρ(s) dV = [β sen(αs)/s] 4πs² ds
dQ = 4πβ s sen(αs) ds.

A aparente singularidade em r = 0 é removível: como sen(αr)/r → α, a densidade tende ao valor finito ρ(0) = πβ/(2R).

2. Interior: carga encerrada para 0 ≤ r ≤ R

Somamos as cascas desde o centro até o raio r:

Qenc(r) = 4πβ ∫₀ʳ s sen(αs) ds.

Integramos por partes, com u = s e dv = sen(αs) ds. Então du = ds e v = −cos(αs)/α:

∫ s sen(αs) ds = −s cos(αs)/α + sen(αs)/α².

Os dois termos da primitiva são nulos em s = 0. Substituindo α = π/(2R), obtemos:

Carga encerrada no interior
Qenc(r) = (16βR²/π)[sen(πr/2R) − (πr/2R) cos(πr/2R)],   0 ≤ r ≤ R.

3. Carga total e região exterior

Na superfície da esfera, r = R, o argumento é π/2. Como sen(π/2) = 1 e cos(π/2) = 0:

Carga total da esfera Q = 16βR²/π

Para qualquer r > R, Qenc(r) = Q = 16βR²/π, pois não há mais carga além do raio R.

4. Campo elétrico no interior

A simetria esférica garante que o campo seja radial e tenha o mesmo módulo em toda superfície gaussiana de raio r. Escrevendo E(r) = Er(r) êr, com êr apontando para fora, a lei de Gauss dá:

∮ E · dA = Er(r) 4πr² = Qenc(r)/ε₀
E(r) = [Qenc(r)/(4πε₀r²)] êr.

Para 0 < r < R, substituímos a carga calculada no item 2:

Campo elétrico no interior
Eint(r) = [4βR²/(π²ε₀r²)] [sen(πr/2R) − (πr/2R) cos(πr/2R)] êr.

No centro, E(0) = 0, pelo limite dessa expressão e pela simetria.

5. Campo elétrico no exterior

Para r > R, a carga encerrada é constante e igual a Q. O campo é o mesmo de uma carga pontual Q localizada no centro:

Eext(r) = [(16βR²/π)/(4πε₀r²)] êr.
Campo elétrico no exterior
Eext(r) = [4βR²/(π²ε₀r²)] êr,   r > R.

Para β > 0, os campos apontam radialmente para fora; para β < 0, para dentro. O módulo do campo é obtido substituindo β por |β| nas expressões. Se β = 0, a carga e o campo são nulos.

6. Continuidade na superfície: r = R

Tomando o limite do campo interno em r = R, o fator entre colchetes vale 1. Para o campo externo, basta substituir r por R:

Eint(R) = [4βR²/(π²ε₀R²)] [1 − (π/2) · 0] êr
Eext(R) = [4βR²/(π²ε₀R²)] êr.
As duas expressões coincidem Eint(R) = Eext(R)
E(R) = [4β/(π²ε₀)] êr.

A densidade volumétrica pode cair de β/R para zero na fronteira sem criar um salto no campo. Não foi incluída uma camada superficial de carga; por isso, a componente radial do campo é contínua em r = R.

Conferência no centro e das unidades

Para t = πr/(2R) pequeno, sen t − t cos t = t³/3 + termos de ordem t⁵. Assim:

Qenc(r) ≈ (2π²β/3R) r³
Eint(r) ≈ [πβ/(6ε₀R)] r êr → 0 quando r → 0.

O campo, portanto, não diverge no centro. Como ρ tem unidade C/m³ e ρ = (β/r) sen(πr/2R), β tem unidade C/m². Logo, βR² tem unidade de carga e β/ε₀ tem unidade N/C, como exigem os resultados.

Fundamentos: integração da densidade volumétrica, simetria esférica e lei de Gauss. Os cálculos e as verificações foram elaborados para este exercício.
