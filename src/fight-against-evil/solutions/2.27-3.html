2.27 · Ponto de campo elétrico nulo

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição do enunciado

Uma carga de +5,0 C encontra-se na origem. Outra carga de −3,0 C está localizada em x = 1,0 m. A que distância(s) finita(s) ao longo do eixo x o campo elétrico será nulo?

1. Examine os sentidos dos campos

Defina a = 1,0 m, a distância entre as cargas. O campo da carga positiva aponta para longe dela; o da negativa aponta em direção a ela. Para o campo resultante ser nulo, os dois campos devem ter módulos iguais e sentidos opostos.

  • À esquerda das duas cargas (x < 0): o campo de +5,0 C aponta para a esquerda e o de −3,0 C, para a direita. A carga positiva tem maior módulo e está mais perto do ponto: |x| < a − x. Portanto, seu campo é sempre mais intenso e não há cancelamento.
  • Entre as cargas (0 < x < a): ambos os campos apontam para a direita. Eles se somam, logo não podem se cancelar.
  • À direita das duas cargas (x > a): o campo de +5,0 C aponta para a direita e o de −3,0 C, para a esquerda. Aqui, a carga de menor módulo está mais perto do ponto, tornando possível o cancelamento.

Assim, basta procurar uma solução na região x > a. Os pontos x = 0 e x = a são excluídos, pois neles o campo das cargas puntiformes é singular.

2. Iguale os módulos na região correta

Para x > a, as distâncias até as cargas positiva e negativa são, respectivamente, x e x − a. Pela lei de Coulomb, com k = 1/(4πε₀):

Ex = k(5,0 C)/x² − k(3,0 C)/(x − a)² = 0.

Cancelando o fator comum k e a unidade de carga:

5/x² = 3/(x − a)².

Como x e x − a são positivos nesta região, podemos extrair a raiz quadrada dos dois lados:

√5/x = √3/(x − a)
√5(x − a) = √3 x
(√5 − √3)x = √5 a.

3. Resolva para a posição

x = a√5/(√5 − √3)
x = a(5 + √15)/2
x = 4,43649… m.
Único ponto finito em que o campo elétrico é nulo x ≈ +4,44 m

O ponto fica à direita das duas cargas, a aproximadamente 4,44 m da origem e 3,44 m da carga −3,0 C. Com os dois algarismos significativos dos dados, a posição é x = +4,4 m.

4. Por que a outra raiz não serve?

Se você resolver diretamente a equação dos módulos, obterá:

5(x − a)² = 3x²
2x² − 10ax + 5a² = 0
x = a(5 ± √15)/2.

A raiz com sinal negativo dá x ≈ 0,564 m. Ela fica entre as cargas, onde os campos apontam no mesmo sentido. Portanto, apenas os módulos são iguais ali; o campo resultante não é zero. Essa raiz também viola a condição x > a usada na montagem da equação do campo.

Conferência do resultado

Na posição obtida, a razão entre as distâncias é:

x/(x − a) = √(5/3).

Logo, x²/(x − a)² = 5/3, exatamente a razão necessária para compensar os módulos das cargas. Os campos têm módulos iguais e sentidos opostos. A análise das outras duas regiões garante que não existe outro ponto finito de cancelamento.

Tentativas anteriores preservadas: tentativa 1 · avaliada como incorreta e tentativa 2 · avaliada como correta.

Fundamento: OpenStax, University Physics Vol. 2, §5.3: lei de Coulomb e superposição. A análise das regiões e os cálculos acima foram elaborados para este exercício.
