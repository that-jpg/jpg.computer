2.74 · Campos que equilibram o peso de partículas

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição do enunciado

Determine os campos elétricos vetoriais necessários para contrabalançar o peso de (a) um elétron e (b) um próton na superfície terrestre.

1. Condição de equilíbrio e eixo vertical

Escolha o eixo y positivo para cima. Na superfície terrestre, adote g = 9,80 m/s². O peso aponta para baixo, enquanto a força elétrica é dada por Fel = qE:

Fg = −mg êy
Fel + Fg = 0
qE − mg êy = 0.

Portanto, a força elétrica deve apontar para cima e ter módulo mg. O campo necessário é:

E = (mg/q) êy,   |E| = mg/|q|.

O sinal da carga determina o sentido do campo: para uma carga positiva, campo e força têm o mesmo sentido; para uma carga negativa, têm sentidos opostos.

2. Item (a): elétron

Para o elétron, qe = −e, com e = 1,602 × 10−19 C e me = 9,109 × 10−31 kg. Assim:

Ee = −(meg/e) êy

meg/e = [(9,109 × 10−31)(9,80)]/(1,602 × 10−19) N/C
meg/e ≈ 5,57 × 10−11 N/C.
Campo que equilibra o elétron Ee ≈ −5,57 × 10−11 êy N/C

Módulo: 5,57 × 10−11 N/C. Direção vertical, para baixo. Como o elétron tem carga negativa, a força elétrica aponta para cima.

3. Item (b): próton

Para o próton, qp = +e e mp = 1,673 × 10−27 kg. Logo:

Ep = +(mpg/e) êy

mpg/e = [(1,673 × 10−27)(9,80)]/(1,602 × 10−19) N/C
mpg/e ≈ 1,02 × 10−7 N/C.
Campo que equilibra o próton Ep ≈ +1,02 × 10−7 êy N/C

Módulo: 1,02 × 10−7 N/C. Direção vertical, para cima. A carga positiva faz a força elétrica apontar no mesmo sentido do campo.

Conferência dos sentidos

Substituindo cada campo em qE, a força elétrica resulta para cima nos dois casos:

Elétron: (−e)[−(meg/e) êy] = +meg êy
Próton: (+e)[+(mpg/e) êy] = +mpg êy.

Essas forças cancelam os respectivos pesos. Os campos são calculados separadamente: um único campo uniforme não pode equilibrar as duas partículas ao mesmo tempo, pois elas exigem sentidos opostos.

Conferência dos módulos e das unidades

As cargas têm o mesmo módulo e, portanto, a razão entre os módulos dos campos é a razão entre as massas:

|Ep|/|Ee| = mp/me ≈ 1,84 × 10³.

O próton exige um campo muito maior porque tem massa muito maior. As unidades são mg/e = (kg · m/s²)/C = N/C.

Fundamentos: equilíbrio de forças, peso e força elétrica F = qE. A derivação e a conferência numérica foram elaboradas para este exercício.
