2.28 · Campo elétrico de três cargas

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição do enunciado

Três cargas encontram-se sobre o eixo y. Duas delas, ambas de valor −q, estão localizadas em y = ±d, enquanto a terceira carga, de valor +2q, encontra-se em y = 0. Derive uma expressão para o campo elétrico no ponto P do eixo.

Onde fica o ponto P?

A versão portuguesa termina em “do eixo”, sem identificá-lo. O problema correspondente na edição inglesa consultada especifica o eixo x (exercício 22.30, p. 705). Portanto, usamos P = (x, 0). A derivação abaixo considera primeiro x > 0; ao final, a expressão é estendida a x < 0.

1. Geometria e simetria

As cargas −q estão em (0, +d) e (0, −d), e a carga +2q está em (0, 0). Defina k = 1/(4πε₀), com q > 0 e d > 0. O símbolo êx indica o vetor unitário no sentido +x. A distância de cada carga negativa até P é a mesma:

r = √(x² + d²).

O campo de uma carga negativa aponta de P para essa carga. Assim, a carga superior produz um campo para a esquerda e para cima, e a inferior, para a esquerda e para baixo. As componentes verticais se cancelam; as horizontais se somam para a esquerda.

2. Campo das duas cargas negativas

Cada uma produz um campo de módulo kq/r². A projeção horizontal tem módulo (kq/r²)(x/r), com sinal negativo para x > 0. Em componentes:

Esup = [kq/(x² + d²)3/2](−x, +d)
Einf = [kq/(x² + d²)3/2](−x, −d).

Somando os dois campos:

Eneg,y = 0
Eneg,x = −2kqx/(x² + d²)3/2.

O denominador tem potência 3/2 porque a lei de Coulomb fornece 1/r² e a projeção acrescenta o fator x/r.

3. Campo da carga central e superposição

Para x > 0, a carga +2q na origem produz um campo para a direita, de módulo 2kq/x². Pela superposição:

Ex = 2kq/x² − 2kqx/(x² + d²)3/2
Ey = 0.
Campo em P = (x, 0), para x > 0 E(P) = 2kq[1/x² − x/(x² + d²)3/2] êx

Para q > 0 e d > 0, o resultado aponta para +x. A contribuição da carga central supera a soma das componentes horizontais das duas cargas negativas.

4. Expressão válida dos dois lados da origem

Se x < 0, a configuração é refletida e o campo muda de sentido. Uma única expressão vetorial válida para qualquer x ≠ 0 é:

E(x, 0) = 2kq[x/|x|³ − x/(x² + d²)3/2] êx.

O ponto x = 0 é excluído: nele está a carga puntiforme +2q, cujo próprio campo é singular.

Conferências do resultado

As componentes em y são exatamente opostas. Além disso, se d tende a zero, as três cargas se sobrepõem e o campo em qualquer x ≠ 0 tende a zero, como exige a carga total −q + 2q − q = 0.

Longe das cargas, para x ≫ d e x > 0, a expansão (1 + d²/x²)−3/2 ≈ 1 − 3d²/(2x²) fornece:

E(P) ≈ (3kqd²/x⁴) êx.

Essa queda mais rápida que 1/x² é consistente com o cancelamento da carga total e com a simetria da distribuição.

Conferência do enunciado: Bauer e Westfall, University Physics, edição inglesa consultada, exercício 22.30, p. 705 (p. 85 do PDF). A identificação do eixo x foi verificada no texto original.

Fundamento: OpenStax, University Physics Vol. 2, §5.3: lei de Coulomb e superposição. A decomposição vetorial e os cálculos acima foram elaborados para este exercício.
