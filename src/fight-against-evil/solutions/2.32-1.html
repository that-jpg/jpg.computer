2.32 · Campo de duas distribuições lineares

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição completa do enunciado

Uma carga por unidade de comprimento +λ está distribuída uniformemente ao longo do semieixo y positivo, desde y = 0 até y = +a. Uma carga por unidade de comprimento −λ está distribuída uniformemente ao longo do semieixo y negativo, desde y = 0 até y = −a. Escreva uma expressão para o campo elétrico (intensidade e orientação) em um ponto do eixo x a uma distância x da origem.

1. Combine elementos simétricos

Considere P = (x, 0), com x > 0, a > 0 e λ > 0. Defina k = 1/(4πε₀). Para cada pequeno trecho de comprimento dy na posição (0, y), com 0 < y < a, escolha o trecho simétrico na posição (0, −y).

Os elementos têm cargas dq+ = +λ dy e dq− = −λ dy, sendo dy um comprimento positivo. Ambos estão à mesma distância de P:

r = √(x² + y²).

O campo da carga positiva aponta para a direita e para baixo. O da carga negativa aponta para a esquerda e para baixo. Portanto, as componentes horizontais se cancelam e as verticais se somam no sentido −y.

2. Escreva o campo de cada par

Nas expressões abaixo, (Ex, Ey) representa as componentes cartesianas do campo. Pela lei de Coulomb:

dE+ = [kλ dy/(x² + y²)3/2](x, −y)
dE− = [kλ dy/(x² + y²)3/2](−x, −y).

A potência 3/2 reúne o fator 1/r² do módulo do campo e o fator 1/r que transforma o deslocamento em um vetor unitário. Somando o par:

dEx = 0
dEy = −2kλ y dy/(x² + y²)3/2.

3. Integre ao longo dos segmentos

Ao variar y de 0 até a, cada par é incluído uma única vez. Assim:

Ex = 0
Ey = −2kλ ∫0a y dy/(x² + y²)3/2.

Usando u = x² + y² e du = 2y dy, a primitiva é:

∫ y dy/(x² + y²)3/2 = −1/√(x² + y²).

Avaliada entre 0 e a, com x > 0, ela fornece:

∫0a y dy/(x² + y²)3/2 = 1/x − 1/√(x² + a²).

4. Intensidade e orientação

Módulo do campo elétrico, para x > 0 E = 2kλ[1/x − 1/√(x² + a²)]

Equivalentemente, E = [λ/(2πε₀)][1/x − 1/√(x² + a²)]. A orientação é paralela ao eixo y, no sentido negativo, em direção ao segmento de carga negativa.

Se êy é o vetor unitário no sentido +y, o resultado vetorial é:

E(x, 0) = −2kλ[1/x − 1/√(x² + a²)] êy, para x > 0.

O colchete é positivo, pois √(x² + a²) > x. Logo, o sinal negativo confirma a orientação encontrada pela simetria. Para usar x como coordenada também à esquerda da origem, basta substituir 1/x por 1/|x|; a direção continua sendo −y. A origem é excluída, pois o campo dessa distribuição linear ideal diverge quando x tende a zero.

Conferências do resultado

Unidades: kλ tem unidade N·m/C e o colchete tem unidade 1/m. O resultado está em N/C, como deve ser.

Longe da distribuição: para x ≫ a, a expansão 1/√(x² + a²) ≈ (1/x)[1 − a²/(2x²)] dá:

E(x, 0) ≈ −(kλa²/x³) êy.

A queda como 1/x³ é a de um dipolo elétrico: a carga total é zero e o momento de dipolo é p = λa² êy. No eixo x, perpendicular ao dipolo, o campo aponta no sentido oposto a p.
