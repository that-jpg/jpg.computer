2.33 · Campo no centro de um semicírculo

Solution available · resolução para consulta

Resolução produzida com auxílio de IA. Este material não conta como exercício resolvido pelo estudante.

Ler a transcrição do enunciado

Uma haste delgada de vidro é dobrada formando um semicírculo de raio R. Uma carga +Q é distribuída uniformemente ao longo da metade superior e a carga −Q é distribuída uniformemente ao longo da metade inferior, como mostra a figura. Determine a intensidade e a orientação do campo elétrico E (em função das componentes) no ponto P, o centro do semicírculo.

1. Geometria e densidade linear

Coloque a origem em P, com o eixo x positivo para a direita e o eixo y positivo para cima. O arco ocupa o lado direito do círculo. Considere Q > 0, R > 0 e k = 1/(4πε₀).

O semicírculo inteiro tem comprimento πR. Cada metade da haste corresponde a um quarto de círculo e tem comprimento πR/2. Portanto, as densidades lineares são:

λ+ = +2Q/(πR)
λ− = −2Q/(πR).

O fator 2 é necessário porque cada carga, +Q ou −Q, ocupa apenas metade do semicírculo.

2. Some elementos simétricos

Escolha um elemento superior no ângulo θ, medido a partir de +x, e seu correspondente inferior no ângulo −θ, com 0 ≤ θ ≤ π/2. As posições são (R cos θ, R sen θ) e (R cos θ, −R sen θ).

Cada elemento tem comprimento ds = R dθ. O módulo de sua carga é:

dq = |λ| ds = (2Q/π) dθ.

Todos os elementos estão à distância R de P. O campo do elemento positivo aponta do arco para P, para a esquerda e para baixo. O campo do elemento negativo aponta de P para o arco, para a direita e para baixo.

Escrevendo os campos como pares de componentes (Ex, Ey):

dE+ = (k dq/R²)(−cos θ, −sen θ)
dE− = (k dq/R²)(+cos θ, −sen θ).

Assim, as componentes horizontais se cancelam e as verticais se somam no sentido −y:

dEx = 0
dEy = −2(k dq/R²) sen θ
dEy = −[4kQ/(πR²)] sen θ dθ.

3. Integre sobre os pares

Integrar θ de 0 até π/2 inclui uma vez cada par de elementos da haste. Logo:

Ex = 0
Ey = −[4kQ/(πR²)] ∫0π/2 sen θ dθ
Ey = −[4kQ/(πR²)][−cos θ]0π/2
Ey = −4kQ/(πR²).
Componentes do campo elétrico no centro P Ex = 0
Ey = −4kQ/(πR²)

O módulo é E = 4kQ/(πR²) = Q/(π²ε₀R²). O campo aponta verticalmente para baixo, no sentido −y, da metade positiva para a metade negativa.

Em forma vetorial, com êy unitário no sentido +y:

E(P) = −[4kQ/(πR²)] êy.

A direção corresponde a −90° (ou 270°) em relação ao eixo +x.

Conferências do resultado

Integrando cada metade separadamente, os campos são:

Esup = [2kQ/(πR²)](−1, −1)
Einf = [2kQ/(πR²)](+1, −1).

A soma confirma Ex = 0 e Ey = −4kQ/(πR²). A carga total zero não implica campo zero em P: os campos verticais produzidos pelas duas metades têm o mesmo sentido.

O fator kQ/R² tem unidade N/C, e 4/π é adimensional. Mantendo Q fixo e dobrando R, o campo fica quatro vezes menor, como exige a lei de Coulomb para uma geometria ampliada na mesma proporção.

Fundamento: OpenStax, University Physics Vol. 2, §5.3: lei de Coulomb e superposição. A decomposição em componentes e a integração acima foram elaboradas para este exercício.
